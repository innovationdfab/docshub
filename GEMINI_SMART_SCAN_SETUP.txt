DOCHUB GEMINI SMART SCAN SETUP

1. Google AI Studio: create/copy a valid Gemini API key.
2. Supabase Dashboard -> Edge Functions -> Secrets:
   GEMINI_API_KEY = YOUR REAL KEY
   GEMINI_MODEL = gemini-2.5-flash
3. Deploy supabase/functions/smart-scan/index.ts.
4. Do not place the Gemini key in frontend index.html.
5. Test Smart Scan and verify the function returns HTTP 200.
